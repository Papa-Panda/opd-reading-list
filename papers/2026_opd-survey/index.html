6在 OPD 主题中的位置

  • 这是 OPD 主题的地图：把 OPD 形式化为 student 采样轨迹上的 f-divergence 最小化，写作 $$\min_\theta\; \mathbb{E}_{x\sim\pi_\theta}\, D_f\big(\pi_\theta(\cdot\mid x)\;\big\|\;\pi_T(\cdot\mid x)\big)$$ 其中 $\pi_\theta$ 是 student、$\pi_T$ 是 teacher。
  • 三设计轴（优化什么 / 信号从哪来 / 如何稳定训练）把散落在 KD、RLHF、模仿学习社区的文献统一到一张表上；本仓库其余 9 篇都是这张地图上的点。
  • 「如何稳定」轴 → many-faces 与 revisiting 的失败模式实证；「信号从哪来」轴 → lightning-opd 的离线预计算；「优化什么」轴 → exopd / uni-opd / self-distilled 的新配方。
  • 阐明了 OPD 与 KL-约束 RL 的联系：KL 约束下的 RL 与 OPD 共享数学骨架，区别在于约束的参考分布与权重是否为恒等。
  • exposure bias 随序列长度平方增长 $O(L^2)$；OPD 把复合误差项往线性方向压——这是 OPD 存在的核心理论动机。

7思考题

  1. f-divergence 统一框架下，forward KL $D_{KL}(\pi_T\|\pi_\theta)$ 与 reverse KL $D_{KL}(\pi_\theta\|\pi_T)$ 在 OPD 里分别对应什么行为（mode-covering vs mode-seeking）？为什么实践中多用 reverse KL？
  2. 三设计轴中的「如何稳定训练」与 RLHF 里的 KL 惩罚项有何异同？KL 约束的参考分布在两边分别扮演什么角色？
