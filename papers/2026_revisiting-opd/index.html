2一句话总结

实证研究 OPD 的失败模式并给出简单修复

3核心命题

  • token-level OPD 相对序列级 reverse-KL 最小化是有偏的，但方差上界更紧
  • 未来 reward 耦合越强梯度方差越大、训练越不稳定。

4方法与机制

  • 三个失败模式：token 监督不均衡、student 前缀上 teacher 指导不可靠、tokenizer / 特殊 token 失配
  • 修复：teacher top-K local support matching（截断 reverse-KL）＋ top-p rollout 采样 ＋ special-token masking

5关键数字

  • 相对标准 sampled-token OPD 基线 +19.8%（单任务推理＋多任务 agentic 推理）

6在 OPD 主题中的位置

  • 与 many-faces-opd 互补的第二份失败模式实证，更偏 token 级机制：token-level OPD 相对序列级 reverse-KL 最小化是有偏的，但方差上界更紧——偏差-方差权衡的经典实例。
  • 核心洞察：未来 reward 耦合越强，梯度方差越大、训练越不稳定——这直接解释了为什么长程推理是 OPD 的重灾区（呼应 prune-opd / f-opd 的动机）。
  • 三个失败模式：token 监督不均衡、student 前缀上 teacher 指导不可靠、tokenizer / 特殊 token 失配；修复：teacher top-K local support matching（截断 reverse-KL）＋ top-p rollout 采样 ＋ special-token masking。
  • 数字：相对标准 sampled-token OPD 基线 +19.8%（单任务推理＋多任务 agentic 推理）——「简单修复」的含金量。

7思考题

  1. token-level OPD 有偏但方差上界更紧——在偏差-方差权衡下，什么时候该选 token-level，什么时候该坚持序列级？top-K local support matching 是如何在这两者之间插值的？
  2. 「未来 reward 耦合越强梯度方差越大」：这对长程推理的 credit assignment 说了什么？prune-opd 的「漂移轨迹上继续打分是算力浪费」是不是同一个现象的工程版表述？
