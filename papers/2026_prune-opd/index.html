2一句话总结

面向长程推理的高效可靠 OPD（剪枝）

3核心命题

  • 长程任务中 student 前缀必然漂离 teacher 思维链，teacher 密集 reward 失去局部可利用性
  • 在已漂移轨迹上继续生成＋打分是纯算力浪费。

4方法与机制

  • top-k overlap 实时监控 student-teacher 局部兼容性
  • 检测到严重 drift 时单调降权后续 reward 并动态截断 rollout
  • 兼容性高时自动扩展训练窗口（不是无脑截短，而是把算力重分配给可靠监督）

5关键数字

  • 训练时间 -37.6% ~ -68.0%
  • AMC / AIME / HMMT 性能保持或提升

6在 OPD 主题中的位置

  • 长程推理中 student 前缀必然漂离 teacher 的思维链，teacher 的密集 reward 失去局部可利用性——在已漂移轨迹上继续生成＋打分是纯算力浪费。
  • 方法：用 top-k overlap 实时监控 student-teacher 局部兼容性；检测到严重 drift 时单调降权后续 reward 并动态截断 rollout；兼容性高时自动扩展训练窗口。
  • 关键设计哲学：不是无脑截短，而是把算力重分配给可靠监督——剪枝的是「不可靠的监督」，不是「长的轨迹」。
  • 数字：训练时间 -37.6% ~ -68.0%；AMC / AIME / HMMT 性能保持或提升。
  • 与 f-opd 同属长程稳定：prune 是同步训练内的算力重分配，f-opd 是异步训练的 freshness 控制——同一病因（drift），两种执行环境下的药方。

7思考题

  1. 用 top-k overlap 做「局部兼容性」的代理：这个启发式什么时候会误判？（比如 teacher 和 student 用不同但等价的推理路径时，overlap 低但监督仍有效？）
  2. 降权＋截断 vs 直接丢弃漂移轨迹：保留「部分可信」的后半段监督价值在哪？单调降权的「单调」为什么重要（和优化稳定性什么关系）？
