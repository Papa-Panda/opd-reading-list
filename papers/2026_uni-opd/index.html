2一句话总结

双视角统一配方统一 OPD

3核心命题

  • OPD 可靠改进的两个根本瓶颈：informative states 探索不足 ＋ teacher 对 student rollouts 的监督不可靠（聚合 token 级指导与 outcome reward 序不一致）。

4方法与机制

  • 双视角配方：student 视角两种 data balancing 策略促 informative state 探索
  • teacher 视角 outcome-guided margin calibration 恢复正/负轨迹间 order consistency

5关键数字

  • 5 domains、16 benchmarks
  • 覆盖 LLM＋MLLM、单/多 teacher、strong-to-weak、跨模态蒸馏

6在 OPD 主题中的位置

  • 直指 OPD 可靠改进的两个根本瓶颈：(1) informative states 探索不足；(2) teacher 对 student rollouts 的监督不可靠——聚合 token 级指导与 outcome reward 序不一致。
  • 双视角配方：student 视角两种 data balancing 策略促进 informative state 探索；teacher 视角 outcome-guided margin calibration 恢复正/负轨迹间的 order consistency。
  • 「序不一致」是精妙的诊断：token 级 teacher 指导说 A 好、B 差，outcome reward 却说 B 好、A 差——监督信号自己打架，蒸馏不可能稳定。
  • 覆盖面最广的一篇：5 domains、16 benchmarks；LLM＋MLLM、单/多 teacher、strong-to-weak、跨模态蒸馏——「统一配方」的野心。
  • 可视为对 many-faces / revisiting 失败模式的正面回答：诊断之后，给出系统性修复框架。

7思考题

  1. 「token 级指导与 outcome reward 序不一致」具体是什么意思？outcome-guided margin calibration 如何恢复正/负轨迹间的 order consistency？
  2. 双视角配方里，student 视角的探索（data balancing）和 teacher 视角的监督（margin calibration），哪个是更紧的瓶颈？在什么任务上结论会反转？
